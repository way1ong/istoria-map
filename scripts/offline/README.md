# Мапа Угорщини для роботи без інтернету

Сучасна мапа, яку застосунок показує без мережі (підкладка `offline` у `data/basemaps.json`), — вирізка з планетарної
збірки Protomaps (дані OpenStreetMap, ODbL; атрибуція «Protomaps © OpenStreetMap») у форматі PMTiles, розбита на частини
по 16 МіБ у `public/offline/` (GitHub не приймає файли понад 100 МБ, а дрібні частини легше докачати після обриву).
Застосунок (`src/offline.ts`) завантажує частини в кеш браузера (Cache Storage) і читає з них тайли сам, через адресу
`pmtiles://offline-hungary`; стиль і шрифти — через `offline://…`. Service worker для цього не потрібен.

## Що в вирізці
- зуми 0–7 — прямокутник 10–29° сх. д., 41–53° пн. ш. (щоб на огляді країни не було порожніх смуг);
- зуми 8–10 — прямокутник 15,6–23,4° сх. д., 45,4–49,0° пн. ш.;
- зуми 11–14 — контур Угорщини (`data/borders/modern.geojson`) з буфером 4 км і кола 5 км довкола місць проєкту
  за кордоном; ближче за 14-й зум мапа збільшує тайли 14-го (вулиці, будинки, стежки вже є).
Поза вирізкою на великих зумах тайли порожні, тло — кольору суходолу.

Розміри (збірка 20261120): до z12 — 113 МБ, до z13 — 180 МБ, до z14 — 319 МБ (узято), до z15 — ~600 МБ.

## Як оновити (нова збірка OpenStreetMap)
Потрібні Python 3 з пакетами `pmtiles` і `shapely` та Node.js. Збірки лежать на https://build.protomaps.com/
(файл `YYYYMMDD.pmtiles`, старі з часом видаляються).

```
cd <будь-яка робоча тека>                       # тут з'явиться кеш каталогів dircache/
BUILD=20261120 python3 <репозиторій>/scripts/offline/extract.py 14 hungary.pmtiles [попередня-вирізка.pmtiles]
cd <репозиторій>
node scripts/offline/split.mjs <робоча тека>/hungary.pmtiles 20261120   # частини й public/offline/hungary.json
node scripts/offline/build-offline-style.mjs                            # стиль public/offline/basemap-hungary.json
npm run build
```

`extract.py` бере з віддаленого файлу лише потрібні тайли запитами Range (злитими, бо сусідні тайли лежать у файлі
поруч); з попередньої вирізки тієї самої збірки тайли беруться без завантаження. Після оновлення назви частин
містять нову дату, тож у застосунку з'явиться кнопка «Оновити» пакета «Сучасна мапа Угорщини».

## Файли
- `extract.py`, `area.py`, `pmremote.py` — вирізка з віддаленої збірки (область, читання каталогів PMTiles з кешем).
- `split.mjs` — частини по 16 МіБ і опис `public/offline/hungary.json`.
- `build-offline-style.mjs` — стиль «light» з `@protomaps/basemaps` без значків (спрайтів офлайн немає).
- `packs-plugin.mjs` — плагін Vite: під час збірки пише `offline/packs.json` з переліком файлів усіх пакетів
  (мапа, шрифти `public/fonts/`, тайли Generalkarte, зображення старих мап) і їхніми версіями.
