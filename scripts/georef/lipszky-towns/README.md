# Мапа Ліпскі 1806: уточнення прив'язки за містами

2026-11-19. Прив'язка `public/georef/lipszky-1806.json` спершу будувалася лише за сіткою градусів на рамці
(конічна модель, `scripts/georef/lipszky-model.json`), тому похибки самої мапи 1806 року (значки міст у середньому
на 1,1 км, до 3,2 км від справжніх місць) переходили на сайт.

1. `towns_osm.json` — координати 62 міст з OpenStreetMap (Nominatim).
2. `crops.py <мітка> <міста>` — вирізки скану навколо місць, куди стара прив'язка ставить справжні координати,
   із сіткою кожні 20 px; на них читається зсув значка міста. `pred.json` — передбачені точки й аркуш.
3. `readings.json` — зчитані зсуви значків (px скану) для 52 міст; неоднозначні міста (Esztergom, Komárom, Tata,
   Szeged, Nagykanizsa, Szatmárnémeti, Nagyvárad, Arad, Eszék, Pozsony) пропущено.
4. `correct.py <старий georef> <новий georef> [болота_старі болота_нові]` — поле поправок: тонкопластинний сплайн
   точно через міста, далі ніж 40 км від найближчого міста згасає до нуля на 80 км; нові опорні точки кожного
   аркуша (сітка ~1300 px, рамка ~650 px, міста) з поправленими координатами; той самий зсув для контурів боліт.
   Друкує перевірку: міста після поправки (≤ 20 м), стики аркушів (медіана 12 м).

Запускати з цієї теки (файли міст і зсувів читаються з поточної теки). Повторний запуск — від прив'язки лише за сіткою
`georef_grid.json` (копія до уточнення), а не від уже уточненої: `python3 -I correct.py georef_grid.json ../../../public/georef/lipszky-1806.json`.
