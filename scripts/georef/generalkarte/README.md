# Generalkarte 1:200 000 на всю Угорщину

Скрипти, якими 2026-11-19 зроблено мапу `generalkarte-1910` (`data/maps/generalkarte-1910.json`,
тайли `public/tiles/generalkarte/{z}/{x}/{y}.avif`). Робоча тека — `GK_WORK`
(типово `scripts/georef/generalkarte/work`, у git не йде).

1. `need.json` — 24 аркуші (34°–41° сх. від Ферро × 46°–49° пн. ш.), що перетинають сучасну Угорщину
   або містять прикордонні місця проєкту; назви файлів з категорії Commons
   «3rd Military Mapping Survey of Austria-Hungary» (скани László Zentai, ELTE).
2. `dl.py` — мініатюри 3840 px з thumb.wikimedia.org (оригінали 3400–3500 px; upload.wikimedia.org віддає 429).
3. `gkdetect.py` — рамка на копіях шириною 3300 px (`work/r3300/`): зовнішня лінія → смуга підписів →
   смуга поділок, межа = внутрішня лінія; 10 відрізків на сторону, крива; результат `gk_det.json`.
4. `gktiles.py` — тайли XYZ 512 px у проєкції Web Mercator, зуми 5–11, AVIF якості 50: кожен піксель
   тайла зуму 11 → lon/lat → аркуш → піксель скану через TPS за 8 точками рамки, з поправкою зсуву
   (−0,000965°, −0,00074°); нижчі зуми — зменшення чотирьох дочірніх тайлів. Тайли покривають прямокутник
   усіх аркушів (там, де аркуша немає, тайл прозорий), щоб MapLibre ніколи не отримував 404.
   Зум 11 (~26 м на піксель) близький до роздільності сканів (~23 м на піксель).
   До 2026-11-19 (до тайлів) аркуші лежали окремими зображеннями 2200 px (`gkwarp.py`, вилучено).
