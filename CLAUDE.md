# istoria-map — історія околиць Göd (Угорщина)

Особистий некомерційний застосунок з історією території навколо Göd (медьє Pest), включно з Vác і Dunakeszi.
Інтерактивна мапа з періодами, картки місць і подій, старі мапи поверх сучасної, розділ з текстами.

## Мова спілкування і змісту
- З користувачем спілкуватися **українською**.
- Інтерфейс двомовний: українська (основна) та угорська, перемикач у шапці.
- Зміст пишеться українською, угорські оригінальні назви в дужках: «Вац (Vác)». Угорський переклад змісту необов'язковий (поле `hu` може бути відсутнє, тоді показується `uk`).

## Користувач і процес
- Користувач працює **лише з телефона**. Не пропонувати локальний запуск, команди «на комп'ютері», IDE.
- Робота в гілці `ccr-*`, далі pull request у `main`, який користувач приймає з телефона. Деплой автоматичний з `main` на GitHub Pages (`.github/workflows/deploy.yml`).
- Користувач редагує дані у веб-редакторі GitHub. Усе, що він може захотіти змінити, має лежати в `data/`, а не в коді.
- Перед великими змінами структури чи стека погоджувати з користувачем. Дрібні правки та доповнення даних робити самостійно.
- Робити поетапно: спершу працююче, потім гарне. Порядок етапів у розділі «План».

## Правила щодо фактів (найважливіше)
- Жодних чисел, дат, назв, координат з пам'яті. **Лише з джерел**, кожен факт має запис у `sources` з URL.
- Неточність позначати явно: `precision: "approximate"` або `"tradition"` для дат; `coordsPrecision: "approximate"` або `"settlement"` для місць.
- Археологічні пам'ятки: координати не точніше, ніж в офіційному/відкритому джерелі. За сумніву ставити `coordsPrecision: "settlement"` (центр населеного пункту) або округлювати до 3 знаків.
- Ліцензії: проєкт некомерційний і приватний, але все одно записувати ліцензію кожного зображення і мапи. Дозволено: суспільне надбання, CC BY, CC BY-SA, CC BY-NC, матеріали з явним дозволом на некомерційне чи освітнє використання. Заборонено: вбудовувати тайли платних сервісів без дозволу (зокрема Arcanum Maps).
- Періодизація (`data/periods.json`) є редакційною рамкою, погодженою з користувачем; межі років беруться з джерел, указаних у файлі.

## Стек
- Vite + TypeScript, без фреймворку. Хеш-маршрутизація (`#/map`, `#/history`, `#/place/:id`, `#/event/:id`, `#/period/:id`).
- Мапа: MapLibre GL JS. Базовий стиль: OpenFreeMap (`https://tiles.openfreemap.org/styles/liberty`), дані OpenStreetMap, ODbL.
- Офлайн (пізніший етап): PMTiles-вирізка регіону з Protomaps у `public/tiles/`, PWA через vite-plugin-pwa.
- Старі мапи: `data/maps/*.json`; типи `image` (скан із 4 кутовими координатами) і `xyz` (тайли, напр. Allmaps).
- Тексти: Markdown у `data/texts/<lang>/<period>.md`, рендер через `marked`.
- Хостинг: GitHub Pages, base `/istoria-map/`.

## Структура
```
data/periods.json      періоди
data/places/*.json     місця (один файл = одне місце)
data/events/*.json     події
data/maps/*.json       старі мапи для накладання
data/routes/*.geojson  шляхи, кордони, рухи (для анімацій)
data/texts/uk|hu/*.md  довгі тексти за періодами
data/README.md         опис полів для редагування з телефона
scripts/validate-data.mjs  перевірка даних (запускається перед build і в CI)
src/                   код застосунку
```

## Команди
- `npm run validate` — перевірка даних.
- `npm run build` — валідація, перевірка типів, збірка в `dist/`.
- Перед комітом завжди запускати `npm run build`.

## Відомі прогалини (станом на 2026-11-15)
- Точність «settlement» лишилася у 3 місць (Székesdűlő, Várdomb-район, млин Sződrákos). Джерела точних координат: категорії Commons (object location) і Nominatim; Overpass через проксі не працює (обрив з'єднання).
- Фото: 20 у 17 місць. Решту брати з Commons, перевіряючи ліцензію на сторінці файлу (API Commons віддає 429, HTML сторінки файлів і категорій працюють).
- Ще не додані: Alag Nepomuki-kápolna, Göd Nemeskéri-kúria фото, вацький замок як окреме місце, Dunakeszi Hősi emlékmű.
- Старі мапи: прив'язка робиться так: скан з Commons через thumb.wikimedia.org (стандартні розміри 960/1920 px; upload.wikimedia.org віддає 429), кути внутрішньої рамки визначаються скриптами в скретчпаді, довготи Ферро − 17°40′, PIL QUAD-трансформація. Умови Arcanum не прочитані (класифікатор блокує запит), Hungaricana виводить список лише через JavaScript.
- Wikipedia API віддає 429; працює лише завантаження HTML статей по одній.
