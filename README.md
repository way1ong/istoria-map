# istoria-map

Особистий застосунок з історією околиць Göd (медьє Pest, Угорщина): інтерактивна мапа з періодами, картки місць і подій, старі мапи поверх сучасної, розділ з текстами.

- Сайт: https://way1ong.github.io/istoria-map/ (автоматичний деплой з гілки `main`)
- Дані для редагування: папка [`data/`](data/README.md)
- Правила проєкту для Claude: [`CLAUDE.md`](CLAUDE.md)

Мапа: MapLibre GL JS, базові тайли OpenFreeMap (дані © OpenStreetMap, ODbL).
